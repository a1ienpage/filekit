# FileKit

**50 бесплатных инструментов для PDF и изображений. Обработка на вашем устройстве.**

![FileKit](preview.png)

Объединение и разделение PDF · страницы и формы · конвертация · OCR · пароль · редактирование изображений · GIF · удаление фона · AI-увеличение.

Автор: **Aliaskar Avgust**.

## Открыть сайт

Включите GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**. Ссылка на сайт появится в этом же разделе после публикации.

## Исходный код

Этот репозиторий содержит готовую статическую сборку. Полный соответствующий исходный код с README, проверками и сборкой находится в [source.zip](source.zip).

Подробности запуска и ограничений: [guide.html](guide.html).

Файлы обрабатываются локально. OCR и AI-увеличение используют включённые модели. Удаление фона при первом запуске загружает модель IMG.LY. Office-конвертация базовая; ограничения указаны в инструментах.
