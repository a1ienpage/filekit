Сайт готов. Вот как его открыть.

FileKit объединяет 50 инструментов для PDF и изображений. Это веб-сайт: Xcode и Android Studio для него не нужны.

На своём Mac

  1. Откройте папку проекта FileKit.
  2. Дважды нажмите Открыть FileKit.command. Запустится локальный сервер и откроется браузер. Окно Terminal оставьте открытым, пока пользуетесь сайтом.
  3. Если macOS блокирует файл, откройте его через правую кнопку → «Открыть» после проверки содержимого. Настройки безопасности отключать не нужно.

Открытие index.html двойным щелчком не подходит: браузеру нужен локальный сервер для PDF-движка и моделей.

Самый простой способ: готовая версия

  1. Распакуйте FileKit-Site.zip.
  2. Создайте на GitHub новый Public репозиторий, например filekit.
  3. Откройте Add file → Upload files. Перетащите содержимое распакованной папки в окно браузера. В корне должны оказаться index.html, папки assets, models и остальные файлы.
  4. Нажмите Commit changes.
  5. В репозитории: Settings → Pages → Deploy from a branch → main → / (root) → Save.
  6. После публикации ссылка появится в том же разделе Pages. Откройте её — сайт работает.

В готовой версии есть source.zip с исходным кодом и лицензиями. Оставьте этот файл на сайте: он нужен для открытого распространения проекта. Файлы node_modules загружать не нужно.

Вариант с автоматической сборкой

  1. Распакуйте FileKit-Source.zip и загрузите содержимое в корень публичного репозитория.
  2. На Mac нажмите ⌘ Shift ., чтобы видеть скрытую папку .github. Она тоже нужна.
  3. В Settings → Pages → Source выберите GitHub Actions.
  4. Во вкладке Actions выберите Publish FileKit → Run workflow. Сборка, тесты и публикация выполнятся автоматически.

Что нужно знать

  • Обработка локальная. Содержимое файлов не загружается на сервер.
  • OCR и AI-увеличение используют модели, включённые в сайт. Для первого запуска удаления фона нужен интернет: модель скачивается у разработчика библиотеки.
  • Конвертация Office базовая. PDF → Word переносит текст; PDF → Excel переносит строки и координаты; PDF → PowerPoint вставляет страницы картинками. Word/Excel/HTML → PDF создают визуальные страницы, текст в таком результате не выделяется.
  • SVG и GIF при обычной обработке становятся растровыми; GIF — первым кадром. Для создания анимации есть отдельный инструмент.
  • Графическая подпись не является сертификатной электронной подписью. OCR может ошибаться. Проверяйте результат перед использованием.
  • Размер исходного проекта небольшой, но установленные библиотеки и сборка занимают больше места. На GitHub отправляются архивы, подготовленные для публикации.
  • PDF/A, восстановление исходной вёрстки Office, перевод, AI-резюме, совместное подписание и URL → PDF не включены.
